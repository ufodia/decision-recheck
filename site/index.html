02 / A bounded workflow

A review you can
follow, question, repeat.

Specialist roles work from explicit requirements and permitted tasks. The useful result is a reviewable decision, with the unknowns left visible.

  1. 01

    Set the brief

    Specify the goal, plan, budget, sources and allowed actions.

  2. 02

    Inspect the task

    Capture scoped sources and isolated browser observations.

  3. 03

    Review the evidence

    Separate supported claims, conflicts and unanswered questions.

  4. 04

    Recheck the decision

    Revisit current sources and relevant tasks when the evidence changes.

↳

“Current” does not mean “true.” An unchanged source can still be wrong. An old task result remains historical until the task is tested again.
